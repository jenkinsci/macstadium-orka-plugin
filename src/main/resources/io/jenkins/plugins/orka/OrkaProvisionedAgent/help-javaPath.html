(Optional) Absolute path to the java executable on the agent, e.g. /opt/homebrew/opt/openjdk@25/bin/java. ${VAR} references are expanded from the environment variables defined in the global or agent node properties. Leave empty to run java from the agent's PATH (SSH Build Agents 3.1021+), which on macOS is the /usr/bin/java stub unless a JDK is linked into /Library/Java/JavaVirtualMachines.
