(Optional) Android emulators to deploy with each agent's VM. Requires Orka 4.0.0 or later and Apple silicon nodes. Each emulator runs on the VM's node and is reachable over ADB only from VMs on that node.

The agent gets these environment variables, numbered from 1 in the order listed here:

  • ORKA_EMULATOR_COUNT
  • ORKA_EMULATOR_n_ADB, _ADB_HOST, _ADB_PORT, _NAME, _CONFIG
  • ORKA_EMULATOR_ADB, _ADB_HOST, _ADB_PORT for the first emulator, and ORKA_EMULATOR_ADB_TARGETS with every host:port, comma separated
  • ORKA_EMULATOR_<CONFIG>_ADB and the same fields, where <CONFIG> is the config name in upper case with other characters replaced by _

The emulator is running when the build starts, but Android may still be booting. The VM image needs adb, and the build connects itself:

adb connect "$ORKA_EMULATOR_ADB"
adb -s "$ORKA_EMULATOR_ADB" shell 'while [ "$(getprop sys.boot_completed)" != 1 ]; do sleep 2; done'
